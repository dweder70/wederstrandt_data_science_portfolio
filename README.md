## 🌟 Portfolio Snapshot

This repository serves as a public-facing portfolio for data science work spanning data preparation, exploratory analysis, predictive modeling, visualization, and generative AI communication. The goal is to present technical depth while keeping the story clear for recruiters and hiring managers.

### 30-Second Recruiter Summary

- Target roles: Data Analyst, Junior Data Scientist
- Core stack: Python, Jupyter, R, R Markdown, Markdown, scikit-learn
- Proof points: multi-source ETL, API-driven automation, fraud detection modeling, time-series forecasting, and stakeholder-facing documentation
- Best starting point: review the flagship projects below, then explore the folder-level README files for deeper context
